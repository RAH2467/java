WEEK 2 — PROGRAM 01 Guide & Verification

Oracle JDK Installation — Windows Procedure

Step 1: Download the Oracle JDK x64 Installer executable from official Oracle website.

Step 2: Run installer wizard, accept license and set target path: C:\Program Files\Java\jdk-17.

Step 3: Configure Windows Environment Variables: Set JAVA_HOME to C:\Program Files\Java\jdk-17 and append %JAVA_HOME%\bin to Path.

WEEK 2 — PROGRAM 02 Guide & Verification

OpenJDK Installation — Windows Procedure

Step 1: Download OpenJDK zip archive from adoptium.net or java.net.

Step 2: Extract the contents to directory C:\OpenJDK\jdk-17.0.2.

Step 3: Update system variables pointing PATH to C:\OpenJDK\jdk-17.0.2\bin.
